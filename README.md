# 基金清盘条款智能识别

> 面向公募基金研究与运营团队的条款核验流水线：把分散在合同、公告和监管披露中的清盘条件，转成可追溯、可复核的结构化结果。

## 为什么做

基金清盘判断通常不是一个简单的关键词搜索问题。关键条款可能出现在不同版本的基金合同中，公告来源也存在缺失、延迟或表述差异。人工逐只打开 PDF、寻找触发条件、整理到 Excel，既耗时，也容易漏掉“连续工作日”“自动触发”等限定语。

这个项目将“找资料—抽条款—判断类型—汇总结果”固化为可重复执行的研究流程，适合批量筛查基金清盘风险、搭建运营底稿或为进一步人工复核生成候选清单。

## 核心能力

- **多来源证据链**：优先读取基金合同/数据服务来源，失败后依次尝试基金公告与监管披露，保留来源、链接和抓取状态。
- **三类条款归类**：识别备案类、备案并满足观察期类、达到条件自动触发终止类，并记录命中的原文片段。
- **规则与语义结合**：同时识别中文数字、阿拉伯数字、工作日/自然日等表达，减少仅靠固定关键词造成的漏判。
- **批量结果交付**：输出管理人汇总、基金明细、统计概览和缓存文件，便于复核、二次分析与增量更新。
- **可恢复运行**：请求结果写入缓存；单只基金失败不阻断整批任务，方便在网络波动后继续处理。

## 工作流

```text
基金清单 Excel
      ↓
获取合同与公告（主来源 → 备选来源 → 监管披露）
      ↓
PDF 文本抽取与条款定位
      ↓
规则分类 + 证据片段保留
      ↓
基金明细 / 管理人汇总 / 统计结果
      ↓
人工复核与后续运营动作
```

## 输出设计

最终 Excel 包含三个视图：

1. **管理人汇总**：按管理人统计不同清盘条款类型与覆盖数量。
2. **基金明细**：基金代码、名称、管理人、条款类型、命中证据、来源与处理状态。
3. **统计概览**：样本量、成功率、各类型占比和异常记录。

同时生成 `results_cache.json`，保存已处理请求及来源状态，支持断点续跑。

## 快速开始

```bash
cd liquidation-clause-skill
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt  # 若本地未提供 requirements，可按 SKILL.md 安装依赖
```

准备基金清单后运行：

```bash
python scripts/pipeline.py \
  --input data/fund_list.xlsx \
  --output outputs/liquidation_results.xlsx \
  --token "$DATAYES_TOKEN"
```

也可以通过环境变量提供 `DATAYES_TOKEN`。字段要求、来源优先级、重试策略和分类规则详见 [`SKILL.md`](SKILL.md)。

## 质量边界

输出结果用于研究筛查和人工复核，不替代法律、合规或基金管理人的正式判断。对于来源缺失、文本解析异常、条款出现冲突的记录，系统会标记状态并保留人工复核入口，而不是强行给出确定结论。
